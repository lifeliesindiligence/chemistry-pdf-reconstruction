# 化学试卷智能重构：第一阶段验证

状态：仅第一阶段的本地验证程序已准备；尚未公开发布、尚未授权账号、尚未发送扫描图像、尚未获得模型结果。第二至第六阶段未开发。

## 范围

- `phase1.mjs`：本地回环 OAuth+PKCE 监听、OpenAI ID token 签名/身份验证、权限检查、账号模型目录查询、一次真实扫描 PNG 视觉识别请求、只在收到 `response.completed` 后报告成功。
- `phase1.test.mjs`：本地离线测试。不使用假网络请求冒充真实授权或识别。
- 无需安装 npm/Python 新依赖；运行时 Node.js 26。不会读取 Hermes 或其他应用的令牌。
- `--open-source-release-confirmed` 是防误触门；只有本应用确实公开开源且用户本人同意登录，才能进入 OAuth。该标志本身不证明 OpenAI 资格。

## 数据边界

真实扫描试卷及验证结果保存在独立的 `D:/app/chem_pdf_reconstruction_private`，不属于可公开源码。OAuth 令牌只驻留于此次运行进程内，既不写源码也不写状态 JSON；关闭后须重新登录。回环监听仅绑定 `127.0.0.1`。仅在账号授予 `chatgpt.tokens.use.direct` 且身份签名校验后，向官方 `POST /v1/responses` 发送一次 PNG，参数为 `store:false, stream:true`。

测试图像源自本机一份化学试卷的扫描页；其 PDF 原文件保留，未修改，也不作为公开示例发布。后续公开仓库需单独核准发布动作、许可证和最终成员清单；不可将整个 `D:/app` 或题库目录添加进仓库。

## 必须完成后才能继续产品开发

1. 确认源码开源发布边界及许可证，然后核准实际发布；目前未执行。
2. 用户本人在官方页面登录并授权，程序读回有效 OAuth 身份和套餐权限。
3. 用真实扫描页进行模型图像请求，记录确实收到的识别结果，再对原图抽样核对。
4. 核对实际账号调用限制、授权失效与重连条件；不得从本地测试推断已通过。
